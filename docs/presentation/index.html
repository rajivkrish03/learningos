04 · Product structure
04 / The differentiator

Don’t jump to the answer.
Climb the help ladder.

Give the least help that gets the learner moving — then more only if needed.

Rung 0

Predict first

Record confidence and a one-line reason before options appear.

Rung 1

Name the axis

Identify the decision dimension — without revealing the answer.

Rung 2

Rule one out

Remove one wrong option and explain why it fails.

Rung 3

Walk the reasoning

Show the decision recipe. Learner still states the final choice.

{ }
Control rule: plain code chooses when to move up the ladder. The LLM does not decide when to reveal help.

07 · Transfer, not convenience
07 / Research integrity

Whatever the result,
report it honestly.

Primary outcome: mean unaided-correct rate on held-out items, per person and per item.

Think-First scores higher

Consistent with the hypothesis if item checks pass. Directional only; no significance claim.

Items are too easy

Ceiling failure. The comparison is uninterpretable; say so plainly.

Scores are similar

No detectable difference at this sample size. Do not invent an effect.

Answer-First scores higher

The direction disfavors withholding. Report it without softening.
